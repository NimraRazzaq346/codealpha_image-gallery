# 🌍 WILD EARTH – Explore Nature
## 💻 Live Demo
**[Explore WILD EARTH]((https://nimrarazzaq346.github.io/codealpha_image-gallery/))**


**Explore the Planet. Discover Nature.**

WILD EARTH is a visually engaging and responsive nature image gallery website designed to showcase beautiful destinations from around the world. It features stunning landscape photography, interactive navigation, smooth animations, and category-based image filtering.

## ✨ Features

- Beautiful nature-inspired user interface.
- Responsive design for desktop, tablet, and mobile.
- Interactive image gallery with destination photography.
- Next and Previous navigation.
- Lightbox image viewing.
- Image hover effects and smooth transitions.
- Category filters for different types of landscapes.
- Continent-based destination filtering.
- Interactive carousel for exploring destinations.
- Modern typography and muted natural color palette.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling, layouts, animations, and responsiveness |
| JavaScript | Gallery navigation, filters, carousel, and lightbox |

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the VS Code Live Server extension.
5. Explore the gallery and its interactive features.

## 🎨 Design Concept

The website uses an editorial nature-inspired design with:

- Warm off-white backgrounds.
- Deep forest green typography.
- Soft muted green accents.
- DM Sans and Playfair Display fonts.
- Clean layouts and elegant transitions.


## 🎯 Project Objective

The objective of this project is to strengthen front-end development skills by creating an interactive, visually appealing, and responsive image gallery using HTML, CSS, and JavaScript.
